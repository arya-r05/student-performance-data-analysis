Student Performance Data Analysis

Project Overview
This project analyzes student performance data using Python.

The goal was to explore how different factors such as gender, test preparation, and lunch type affect academic performance.

Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

Dataset
Students Performance in Exams Dataset (Kaggle)

Key Insights

- Male students scored slightly higher in mathematics.
- Female students performed better in reading and writing.
- Students who completed the test preparation course scored higher in all subjects.
- Students with standard lunch performed better than those with free/reduced lunch.

Conclusion
The analysis shows that preparation and socio-economic factors significantly influence student academic outcomes.
